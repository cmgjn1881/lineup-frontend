## 💡 프로젝트 개요 (Overview)

본 웹 클라이언트는 아이폰 및 아이패드 사용자들이 앱처럼 설치하고 사용할 수 있도록 개발되었습니다. 조기축구 팀의 전술 관리 및 팀 운영을 목표로 합니다.

사용자는 직관적인 드래그 앤 드롭 인터페이스를 통해 축구 전술을 구상하고, 팀 정보와 포메이션을 저장 및 공유할 수 있습니다.

### 주요 기능
1.  **소셜 로그인:** 카카오 로그인을 통한 간편한 회원가입 및 로그인
2.  **전술 관리:** 팀, 선수, 포메이션에 대한 생성, 수정, 삭제 (CRUD) 관리 기능 제공
3.  **포메이션 설계:** 필드 위에서 선수 아이콘을 드래그하여 위치를 조정하는 직관적인 설계 도구
4.  **간편 공유:** 생성된 포메이션을 팀원들과 쉽게 공유할 수 있는 기능
